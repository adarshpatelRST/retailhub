## 1. ARCHITECTURAL REQUIREMENTS & CONSTRAINTS
1. Generate complete, production-grade, compilable TypeScript and configuration files for Chunk B1.
2. Adhere strictly to the provided Microsoft SQL Server Prisma schema with exact field names, data types, indexes, and relations.

4. DETAILED IMPLEMENTATION RULES
Correlation ID & Interceptors:

In TransformInterceptor, read X-Correlation-Id from request headers or generate a UUID v4. Return all successful payload wrapped in ApiResponse<T>.

In AllExceptionsFilter, catch all exceptions, extract or generate correlation ID, log the error stack, and return an HTTP response matching ApiErrorResponse.

Audit Logging:

In AuditInterceptor, inspect mutating HTTP methods (POST, PUT, PATCH, DELETE). Clone the request body, delete sensitive keys (password, token, secret, authorization), and record action, entityName, and newValues into AuditLog via PrismaService.

Data Scoping Guard:

DataScopeGuard inspects req.user.

If STORE_MANAGER, query UserStoreAssignment for user's store IDs and set req.dataScope = { storeId: { in: storeIds } }.

If REGIONAL_MANAGER, query UserRegionAssignment and set req.dataScope = { store: { regionId: { in: regionIds } } }.

If EXECUTIVE or ADMIN, set req.dataScope = {}.

Bootstrap & Swagger:

In src/main.ts, prefix all routes with api/v1.

Enable CORS.

Attach ValidationPipe with { whitelist: true, transform: true }.

Configure Swagger documentation at /api/docs.

Register AllExceptionsFilter and TransformInterceptor globally.
