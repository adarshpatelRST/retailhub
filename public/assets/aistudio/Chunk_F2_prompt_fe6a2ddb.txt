## 3. DETAILED IMPLEMENTATION SPECIFICATIONS

### A. Product Core Module (`src/modules/operations/product/`)

1. **`api/product.api.ts`**:
   - `getProducts(params)`: Calls `GET /api/v1/products`.
   - `getProductById(id)`: Calls `GET /api/v1/products/${id}`.
   - `createProduct(dto)`: Calls `POST /api/v1/products`.
   - `updateProduct(id, dto)`: Calls `PUT /api/v1/products/${id}`.
   - `deleteProduct(id)`: Calls `DELETE /api/v1/products/${id}` (soft-delete).
   - `getCategoriesTree()`: Calls `GET /api/v1/categories`.
   - `getBrands()`: Calls `GET /api/v1/brands`.
   - `uploadBatchProducts(products)`: Calls `POST /api/v1/products/batch`.

2. **`components/CategoryTreeCombobox.tsx`**:
   - Single Popover (`DropSearch` pattern).
   - State: `currentPath: CategoryNode[]` (history of drilled categories, starting with `[]`).
   - Breadcrumb navigation:
     - Renders `🏠 All` when at root.
     - When drilled down, renders clickable breadcrumb pills: `🏠 All > Groceries > Cooking Oils`. Clicking any pill jumps directly to that level.
   - Search input: Searches across all descendants. If searching, flattens matching leaf nodes showing `Leaf Name (Parent > Grandparent)`.
   - Folder click: If category has `subCategories.length > 0`, pushes node to `currentPath` and renders sub-items with item counter badge `(14) ➔`.
   - Leaf click: If no subcategories, calls `onSelect(category.id)` and closes popover.
   - Keyboard: `ArrowRight` drills in, `ArrowLeft` navigates back up.

3. **`components/CreateProductModal.tsx`**:
   - Zod schema:
     ```typescript
     export const createProductSchema = z.object({
       sku: z.string().min(3).regex(/^[A-Z0-9-]+$/, "Must be uppercase alphanumeric"),
       productCode: z.string().min(8, "Barcode must be at least 8 digits"),
       name: z.string().min(2, "Product name is required"),
       description: z.string().optional(),
       brandId: z.string().uuid("Please select a brand"),
       categoryId: z.string().uuid("Please select a category"),
       unitOfMeasure: z.enum(["PIECE", "LITRE", "KG", "PACK"]),
       costPrice: z.coerce.number().positive("Cost price must be positive"),
       sellingPrice: z.coerce.number().positive("Selling price must be positive"),
       mrp: z.coerce.number().positive("MRP must be positive"),
     }).refine((data) => data.sellingPrice <= data.mrp, {
       message: "Store selling price cannot exceed MRP",
       path: ["sellingPrice"],
     });
     ```
   - Responsive: `sm:max-w-2xl` dialog on desktop; full-height bottom sheet on mobile with sticky bottom buttons (`fixed bottom-0 left-0 right-0 p-4 border-t bg-background flex justify-end gap-2`).

4. **`components/CsvUploadModal.tsx`**:
   - Clean native file input: `<input type="file" accept=".csv" />`.
   - "Download Sample CSV Template" button.
   - When file selected:
     - Parses CSV headers (`sku,productCode,name,brandCode,categoryCode,unitOfMeasure,costPrice,sellingPrice,mrp`).
     - Splits into chunks of 1,000 rows.
     - Iterates through chunks: updates progress bar (`Progress` component: `(currentChunk / totalChunks) * 100`).
     - Shows final summary: `Total: X, Inserted: Y, Updated/Skipped: Z, Failed: W`.

5. **`ProductListView.tsx`**:
   - Uses `PageLayout`.
   - Actions slot: "Import SKUs (CSV)" button (opens `CsvUploadModal`) and "Add Product" button (opens `CreateProductModal`, visible to `ADMIN`).
   - Filter bar:
     - `RH_SearchBox` with barcode-first search.
     - Brand and Category filter dropdowns (`DropSearch`).
     - On mobile (< 640px), filter bar collapses into a "Filters" button opening a bottom `Sheet`.
   - Table:
     - On desktop/tablet (>= 640px): `ServerDataTable` with columns: SKU, Barcode, Product Name, UOM, Pricing (Strikethrough MRP + Bold Selling Price), Total Stock Badge, Status, Actions.
     - On mobile (< 640px): Renders list of `ProductCardMobile` components.
