- `createStoreRequest(dto)`: `POST /api/v1/recommendations/store-request`

### B. Enhanced Side-by-Side Comparison (`components/SideBySideStoreCard.tsx`)
- Props:
  - `destStore`: `{ name, code, format, currentStock, ads, currentDOI }`
  - `sourceStore`: `{ name, code, format, currentStock, ads, currentDOI, distanceKm } | null`
  - `transferQty`: `number`
  - `unitCost`: `number`
- Calculations:
  - `destStockAfter = destStore.currentStock + transferQty`
  - `destDOIAfter = destStore.ads > 0 ? destStockAfter / destStore.ads : 999`
  - `srcStockAfter = sourceStore ? sourceStore.currentStock - transferQty : 0`
  - `srcDOIAfter = sourceStore && sourceStore.ads > 0 ? srcStockAfter / sourceStore.ads : 999`
  - `estTransitHours = sourceStore ? Math.max(0.5, Number((sourceStore.distanceKm / 50).toFixed(1))) : 0`
  - `transferValue = transferQty * unitCost`
- Renders top route banner with distance, transit estimate, and ₹ valuation, followed by a 2-column grid (`grid-cols-1 sm:grid-cols-2 gap-4`) with before/after metrics and `RH_DOIGauge` bars. If `sourceStore == null`, renders the `[🏭 Central Supply / Mother Hub]` card in the source column.

### C. Candidate Switcher & Safety Guardrail (`components/CandidateStoreSelector.tsx`)
- Props: `candidates: CandidateStoreDto[]`, `selectedStoreId: string | null`, `onStoreChange(id)`, `quantity: number`, `onQuantityChange(qty)`, `onValidationChange(isValid: boolean)`.
- Calculates `maxSafeTransfer = Math.floor(selectedCandidate.availableStock - (7.0 * selectedCandidate.ads))`.
- Calculates `projectedDonorDOI = (selectedCandidate.availableStock - quantity) / selectedCandidate.ads`.
- If `projectedDonorDOI <= 7.0`:
  - Calls `onValidationChange(false)`.
  - Renders destructive red banner: `"Safety Violation: Sourcing ${quantity} units drops ${selectedCandidate.storeName} to ${projectedDonorDOI.toFixed(1)} days DOI (Minimum required is 7.0 days). Maximum safe transfer is ${maxSafeTransfer} units."`
- Otherwise calls `onValidationChange(true)` and shows green check banner.
