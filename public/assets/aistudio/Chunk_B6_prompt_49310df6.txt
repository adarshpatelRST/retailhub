rebalance-facts.dto.ts:
Define StoreMetrics (storeName, currentStock, averageDailySales, doi, statusOrRisk) and RebalanceFactsDto (productSku, productName, categoryName, destination, source (nullable), recommendedQuantity, projectedPostDOI, isManualRequest).

rebalance-narrative.prompt.ts:

System prompt instructs model as Senior Retail Logistics Analyst.

Enforce strict adherence to input JSON facts; output must be exactly 2-3 concise, professional sentences explaining why the transfer protects destination without compromising source.

langchain.provider.ts:

Implements ILlmProvider.

Inspects process.env.LLM_PROVIDER (default 'GEMINI').

If 'GEMINI', instantiate ChatGoogleGenerativeAI with modelName: process.env.LLM_MODEL_NAME || 'gemini-1.5-flash', apiKey: process.env.GEMINI_API_KEY.

If 'OPENAI', instantiate ChatOpenAI with modelName: process.env.LLM_MODEL_NAME || 'gpt-4o-mini', apiKey: process.env.OPENAI_API_KEY.

Runs REBALANCE_NARRATIVE_PROMPT.pipe(this.model).pipe(new StringOutputParser()).

template-fallback.provider.ts:

Implements ILlmProvider.

Returns deterministic templated narrative if source exists:
"${dest.storeName} is facing an imminent stock-out with ${dest.doi.toFixed(1)} days of inventory remaining under daily sales of ${dest.averageDailySales.toFixed(1)} units. ${src.storeName} currently holds ${src.currentStock.toFixed(0)} units (${src.doi.toFixed(1)} days DOI) of excess stock. Transferring ${qty.toFixed(0)} units extends ${dest.storeName}'s buffer to ${postDestDOI} days while leaving ${src.storeName} safely protected at ${postSrcDOI} days DOI."

Handles Central Supply fallback if source is null.

ai.service.ts:

getOrGenerateExplanation(recommendationId: string, facts: RebalanceFactsDto):

Checks prisma.recommendation.findUnique for cached aiExplanation. If present, return it immediately.

Calls this.llmProvider.generateNarrative(facts) with Promise.race for a 4000ms timeout.

On error or timeout, falls back to this.fallbackProvider.generateNarrative(facts).

Updates prisma.recommendation.update({ where: { id: recommendationId }, data: { aiExplanation } }).

Returns explanation.

ActionCenterService (action-center.service.ts):

findAll(query: RecommendationQueryDto, dataScope?: any):

Applies dataScope constraints (Store Managers only see recommendations where storeId equals their assigned store).

Joins product, store (destination), fromStore (source), and evidence.

Orders by priority: 'HIGH' -> 'MEDIUM' -> 'LOW', then createdAt DESC.

findById(id: string):

Returns single recommendation with joined product, stores, evidence, and action history.

getAiExplanation(id: string):

Builds RebalanceFactsDto from recommendation and evidence records.

Calls AiService.getOrGenerateExplanation(id, facts) and returns { explanation: string }.

approve(id: string, dto: ApproveRecommendationDto, user: any):

Runs inside prisma.$transaction:

Checks recommendation exists and status IN ('OPEN', 'MODIFIED').

If fromStoreId != null:

Reads source Inventory row with version. Checks availableQuantity >= recommendedQuantity.

Decrements source availableQuantity, increments inTransitQuantity, increments version.

Inserts InventoryMovement (movementType: 'TRANSFER_OUT_DISPATCH').

Generates StockTransfer with status 'APPROVED_IN_TRANSIT' and logistics details from DTO.

If fromStoreId == null (Central Supply):

Increments destination Inventory.availableQuantity.

Inserts InventoryMovement (movementType: 'INWARD_RECEIPT', referenceType: 'CENTRAL_SUPPLY').

Updates Recommendation: status = 'COMPLETED', stockTransferId = transfer?.id.

Inserts Action (recommendationId: id, actionType: 'APPROVE', actionedBy: user.userId, comments: dto.comments).

Inserts ActionHistory (previousStatus, newStatus: 'COMPLETED', changedBy: user.userId).

batchApprove(dto: BatchApproveDto, user: any):

Iterates through dto.recommendationIds and executes approve for each.

Catches errors per item; returns { processedCount, succeededCount, failedCount, failures }.

modify(id: string, dto: ModifyRecommendationDto, user: any):

Reads donor store Inventory and rolling ADS from VelocityService.

Enforce 7-Day Safety:
donorPostDOI = (donorAvailableStock - dto.modifiedQuantity) / donorADS.
If donorPostDOI <= 7.0, throws BadRequestException('Donor store DOI will drop to ' + donorPostDOI.toFixed(1) + ' days, violating 7-day safety threshold.').

Updates Recommendation: fromStoreId = dto.selectedFromStoreId, recommendedQuantity = dto.modifiedQuantity, status = 'MODIFIED'.

Inserts Action (actionType: 'MODIFY') and ActionHistory recording mandatory comments.

reject(id: string, dto: RejectRecommendationDto, user: any):

Updates Recommendation: status = 'REJECTED'.

Inserts Action (actionType: 'REJECT') and ActionHistory recording mandatory reason.

createStoreRequest(dto: StoreRequestDto, user: any):

Creates Recommendation: storeId = user.assignedStoreId, productId = dto.productId, recommendedQuantity = dto.requestedQuantity, isManualRequest = true, requestedByUserId = user.userId, recommendationType = 'MANUAL_STORE_REQUEST'.

Calls CandidateRankingService.findAndRankCandidates to bind Rank 1 donor store to fromStoreId and attaches candidate evidence.
